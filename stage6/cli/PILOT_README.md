# Ex Real-User Pilot — 测试指南

感谢你参与测试。这个 Pilot 想验证一件事：**把一个人「蒸馏」成一个 AI 前任（Ex）后，你愿不愿意真正和它聊、纠正它、第二天还回来**。

这不是最终产品，是一个技术验证版 CLI。你的真实使用和反馈，将决定这个方向值不值得继续做。

---

## 0. 快速开始 / 首次启动（推荐新手路径）

> 你只需要会「双击」和「粘贴一个 Key」。不需要懂 Python、命令行或环境变量。

1. 打开文件夹：`stage6\cli`
2. **双击 `start.bat`**
3. 如果程序提示 `DeepSeek API Key:`——输入你自己的 DeepSeek API Key（**输入不会回显**，直接回车）
4. 程序自动配置好一切，并进入测试引导
5. 按引导完成：创建 Ex → 导入 → 聊天 → 纠正 → 确认/忽略 → 问卷

如果程序没有提示输入 Key，说明你**系统里已经配置过** API Key，会直接使用。

---

## 1. Pilot 是什么

- 你在本地用命令行创建一个「Ex」（模拟某个你想怀念/告别/对话的人）。
- 你导入一段聊天记录（或先用内置示例），系统自动生成它的「人格 + 记忆」。
- 你开始和它对话；说错/不像时你可以**纠正**它，它会记住。
- 你退出，过一阵再回来，看它是否还记得你纠正过的东西。
- 全程本地运行，数据只在你自己的机器上。

## 2. 你要做什么（总览）

**新手最简路径：**
```
1. 双击 start.bat
2. （如提示）输入你自己的 DeepSeek API Key（不回显）
3. 自动进入引导 → 创建 Ex
4. 导入聊天（或用示例）
5. 开始聊天（多聊几轮）
6. 纠正它一次（如：不对，她其实话痨）
7. 确认/忽略纠正
8. 退出
9. （过一会/第二天）再进来，看它记不记得
10. 回答一份简短问卷
11. 把记录文件交给项目方
```

全程大约 **15–30 分钟**（不含你选择「第二天再回来」的那一次）。

## 3. 环境要求

- 一台 **Windows** 电脑（本启动器面向 Windows；macOS/Linux 见第 4.2 节手动方式）
- 已安装 **Python 3.10+**（安装时勾选 "Add to PATH"）
- 一个 **DeepSeek API Key**（你自己的）
- **不需要**懂命令行 / 环境变量（走 start.bat 即可）

## 4. 启动方式

### 4.1 新手推荐：双击 start.bat

文件位置：`stage6\cli\start.bat`

1. 双击它
2. 若没有检测到已有 Key，会出现：`DeepSeek API Key:` —— 输入你自己的 DeepSeek API Key（**不回显**），回车
3. 自动配置好 provider / model，并进入测试引导
4. 若窗口一闪而过，见第 16 节故障排查

### 4.2 高级用户 / 手动启动方式（开发者与排障用）

如果你已经在自己**系统环境变量**里配好了 Key，start.bat 会直接使用、不重复询问。

手动方式（PowerShell）：
```powershell
cd stage6\cli
$env:DEEPSEEK_API = 'YOUR_API_KEY'
$env:OPENAI_BASE_URL = 'https://api.deepseek.com'
$env:EX_PROVIDER = 'openai'
$env:EX_MODEL = 'deepseek-chat'
$env:EX_REAL = '1'
python pilot_recorder.py --user 你的代号
```
或一步到位（等同 start.bat）：
```powershell
cd stage6\cli
python start.py --user 你的代号
```

> Windows cmd：`set DEEPSEEK_API=YOUR_API_KEY`（每项一行）
> macOS/Linux：用 `export DEEPSEEK_API=...` 等（同上 5 行）再 `python pilot_recorder.py`

## 5. API Provider / Model 配置

| 变量 | 含义 | 示例 |
|---|---|---|
| `DEEPSEEK_API` | 你的 API Key | `YOUR_API_KEY` |
| `OPENAI_BASE_URL` | provider 端点 | `https://api.deepseek.com` |
| `EX_MODEL` | 模型名 | `deepseek-chat` |
| `EX_PROVIDER` | provider 类型 | `openai`（DeepSeek 用 openai 兼容） |
| `EX_REAL` | 是否用真实模型 | `1`（真实） |

## 6. API Key 安全说明（重要）

- **API Key 是你自己的 Key**，只在你自己的机器上、本次启动使用。
- **不要把 Key 发给项目作者、Claude、ChatGPT，或任何人。** 不要截图、不要复制到问卷/群聊。
- Key **只存在于本次启动的进程内存**。
  - 不写入项目文件、配置文件、`.env`、Git、`pilot_data` 或日志。
  - **关闭程序后 Key 消失。**
  - 下次启动需要重新输入，**除非**你自己的系统环境变量里已经配置了 Key。
- 走 `start.bat` 时输入 Key 是**不回显**的（屏幕不显示你敲了什么）。
- 如果你发现 Key 出现在任何日志/输出/文件里：**立即停止**，并告诉项目方。

> 高级方式里用 `YOUR_API_KEY` 占位，请替换成你自己的 Key。

## 7. 创建 Ex

启动（`start.bat` 或 `pilot_recorder.py`）后，第一步会让你给 Ex 起代号：

```
1) 给这个 Ex 起个代号: xiaoming
```

（只能用小写字母/数字/`-`/`_`，≤40 字符。）

## 8. 导入聊天记录

```
2) 导入聊天记录。
   选项A: 用内置示例 messages（演示用）
   选项B: 提供你自己的 ChatImport JSON 路径
```

- **A**：先用内置示例跑通流程（推荐第一次用）。
- **B**：如果你有自己的微信/QQ 导出转成的 ChatImport JSON，给路径即可。若没有现成格式，建议先用 A。

## 9. 开始聊天

```
3) 开始聊天。多聊几轮。想纠正 ta 就正常说。
你> 
```

直接打字聊天。多聊几轮，感受它「像不像」。
- 输入 `/quit` 结束聊天。

## 10. 如何进行 Correction（纠正）

聊天中如果你觉得它说错了、或某件事其实不是那样，直接像对人说话一样纠正它。例如：

```
你> 不对，她其实话痨，特别能说那种。
```

系统会识别这是纠正，并**弹出纠正建议**。

## 11. Confirm / Reject

弹窗后选择确认或忽略：

```
纠正建议: 把 mi_A 纠正为「话痨，特别能说那种」
确认?(y/n): y      ← 确认（它记住）；n = 忽略
```

- `y`：它会把这条纠正写入长期记忆。
- `n`：本次不记住。

## 12. 退出并再次进入

- 聊天中输 `/quit` 退出（Key 随之从内存消失）。
- **过一会（最好第二天）** 再次打开：**再次双击 `start.bat`**，重新输入你的 Key（若提示），进入引导。
  - 新手：双击 `start.bat`
  - 高级：`python pilot_recorder.py --user 你的代号`
- 重新进入后会恢复你的 Ex，新会话会加载已保存的长期记忆。**重点体验：它还记得你上次纠正过的东西吗？**

## 13. 完成反馈问卷

结束聊天后，脚本会问你 8 个问题（1–5 打分或文字）：

1. 像不像 ta？（1不像–5很像）
2. 最像的地方？
3. 最不像 / 出戏的地方？
4. 明天还愿意回来聊吗？（y/n）
5. 它记得你纠正过的吗？（y/n/没试）
6. 纠正流程打断感？（1很打断–5很顺）
7. 在哪一步卡住 / 想退出？
8. 其他想说的？

请**如实回答**。我们**不需要好评**，只需要真实的感受——尤其「哪里不像」「哪一步让你想退出」。

## 14. pilot_data 文件在哪

你的记录会存在：

```
stage6/cli/pilot_data/<你的代号>.json
```

这个文件只含**行为指标 + 你的问卷回答 + 时间**，不含 API Key、不含聊天正文、不含不必要的个人信息。

## 15. 如何把结果交给项目方

把 `pilot_data/<你的代号>.json` 这个文件发回给项目方即可。

**不要**发 API Key；**不要**发原始聊天记录（除非另有说明）。

## 16. 常见错误及处理

| 现象 | 处理 |
|---|---|
| 双击 start.bat 后窗口一闪而过 | 从终端手动运行看错误：在 `stage6\cli` 下执行 `python start.py`（见第 4.2 节）|
| 找不到 Python | 安装 Python 3.10+，安装时勾选 "Add to PATH"，重开终端再试 |
| API Key 无效 / 一直「服务没响应」 | 用**你自己的有效 DeepSeek API Key**；检查网络/额度；稍后再试 |
| 提示缺 API Key（手动方式） | 确认 `DEEPSEEK_API` 已设置（每个新终端都要重设）；或直接用 start.bat |
| `ex` 已存在 | 换个代号，或用 `delete` 命令删掉旧的 |
| 聊天中模型「接不住」 | 换句话再说；这不影响流程 |
| 它说「谁啊？哪个她」 | 正常现象（本项目已知限制）；换个说法带上下文再问 |
| 导入失败 | 确认你的 JSON 是合法 ChatImport；或先用示例 A |

> ⚠️ **不要把 API Key 截图或发送给任何人。** 输入时它不回显；若你发现它出现在任何输出/文件里，立即停止并报告。

## 17. 大约需要多久

- 首次完整流程（含导入 + 聊天 + 问卷）：**15–30 分钟**。
- 第二次回访验证记忆：**5 分钟**。

## 18. 不应该做什么

- 不要输入/分享任何人的真实隐私或敏感信息来做测试。
- 不要把这个 Ex 当成真人去骚扰、联系、或产生现实依赖。
- 不要把 API Key、原始聊天、他人隐私发到问卷或群聊。
- 不要为了「配合测试」给好评——真实反馈才最有价值。
- 如果聊到让你不适的内容，随时退出即可。
