# Clean-machine 测试清单（测试者不需要懂 Python）

> 目标：在一台**没有安装 Python、没有任何本项目依赖**的普通 Windows 电脑上，验证：
> 「解压 ZIP → 双击 EXE → 输入自己的 Key → 完整走完 Pilot」。
> 你不需要懂编程。按下面每一步做，并在最后填结果。

## 需要什么环境（测试机）
- 一台普通 Windows 电脑（Win10/11 均可）。
- **不需要** Python；**不需要**装任何依赖。
- 需要联网（对话要连 DeepSeek）。
- 需要**你自己的 DeepSeek API Key**（测试方不会提供、也不应收你的 Key）。

## 测试者要做什么

### A. 确认这台机器没有 Python
1. 按 `Win` 键 → 输入 `cmd` → 回车（打开命令行）。
2. 输入：`python --version` 回车。
   - 若显示 `'python' 不是内部或外部命令`（或类似"找不到"）→ **✓ 无 Python**（符合要求）。
   - 若显示一个版本号（如 Python 3.x）→ 记下它，但**仍可继续测试**（先说明机器有 Python）。

### B. 解压
1. 把 `ex-ai-pilot.zip` 拷到这台机器。
2. 右键 → 全部解压缩 → 解压到一个文件夹（如桌面 `ex-ai-pilot`）。
3. 打开该文件夹，确认能看到：`ex-ai-pilot.exe` 和一个 `_internal` 文件夹。

### C. 双击启动
1. **双击 `ex-ai-pilot.exe`**。
2. 会弹出一个命令行窗口（黑色）。
3. 若提示 `DeepSeek API Key:` → 输入**你自己的 Key**（屏幕不会显示你敲的字）→ 回车。
   - 若没提示（直接进入）→ 说明这台机器系统里已配置过 Key，直接用。

### D. 走完 Pilot 流程
按窗口里的引导，逐步做：
1. **Create Ex**：给它起个代号（小写字母/数字）。
2. **Import**：选 A（用内置示例）。
3. **Chat**：多聊几句（比如"在吗""你觉得她话多话少？"）。
4. **Correction**：输入一句纠正，如 `不对，她其实话痨，特别能说那种。`
5. **Confirm**：弹出纠正建议后，输入 `y` 确认。
6. **退出**：输入 `/quit`。
7. 窗口会问你几个问卷问题，随便如实填（或直接回车跳过）。

### E. 重新打开，验证记忆
1. **再次双击 `ex-ai-pilot.exe`**，重新输入 Key（若提示）。
2. 再次 Create Ex？—— **不要新建**。看引导是否让你**选/回到已有的那个 Ex**（代号就是你上次起的）。
   - 注：当前 Pilot 引导每次会新建 Ex。若它要求新代号，说明"恢复既有 Ex"这步在 Pilot 引导里还不直观——**请如实记录你看到的现象**（见 F.8）。
3. 若能进入/问到上次的事：问它 `还记得上次纠正说她话痨吗？`，看它记不记得。

### F. 记录结果（每题填 是/否/现象）
1. 无 Python（或机器有 Python，如实注明）：____
2. 解压后能看到 exe + _internal：____
3. 双击能启动、出现命令行窗口：____
4. 能输入自己的 Key 且不回显：____
5. Create Ex 成功：____
6. Import（示例 A）成功、生成了 persona：____
7. Chat 有真实回复：____
8. 退出后**再次启动**：是回到旧 Ex，还是又让新建？____
9. （若回到旧 Ex）它记得上次纠正吗：____
10. 有没有在哪一步报错/卡住/闪退：____
11. 窗口一闪而过无法运行？如果是，请记下（可能需命令行看报错）。

### G. 数据与 Key 安全（项目方检查用，你可选做）
- 打开文件夹 `%USERPROFILE%\.ex_ai\`：
  - 应看到 `exes` / `sessions` / `pilot_data`。
  - `exes\<你的代号>\persona_memory.json` 应存在。
  - `pilot_data\` 里应有你的记录文件。
- **检查有没有出现你的 API Key**：在 `.ex_ai` 文件夹里搜你的 Key 前几位（用记事本打开几个 json 看）。**正常情况不应出现。**
- **不要把 Key 发给任何人。** 如果发现 Key 出现在任何文件里 → 记下并告诉项目方，立即停止。

## 如何判断 PASS / FAIL
- **PASS（关键路径）**：能启动 → 输 Key → Create → Import → Chat → Correction → Confirm → 退出 → 数据落在 `.ex_ai\`。
- **PASS（记忆）**：再次启动能回到旧 Ex 且记得纠正（若引导不支持"回旧 Ex"，此项记"现象"不判 FAIL）。
- **FAIL**：双击闪退、无法输 Key、Create/Import 报错、`.ex_ai` 没生成、Key 落盘出现。
